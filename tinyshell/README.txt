Περιγραφή Συστήματος
Το Tiny Shell είναι ένα απλό CLI (Command Line Interface) που αναπτύχθηκε σε C, το οποίο μιμείται τη βασική λειτουργικότητα ενός σύγχρονου Unix/Linux shell. Χρησιμοποιεί τις system calls fork(), execvp()/execve() και waitpid() για την εκτέλεση εξωτερικών προγραμμάτων.

Χαρακτηριστικά
1.  Prompt: Εμφανίζει το prompt tiny_shell>  για την είσοδο εντολών.
2.  Εκτέλεση Εντολών: Εκτελεί οποιαδήποτε εντολή είναι διαθέσιμη στο σύστημα (π.χ., ls, pwd, κ.λπ.) δημιουργώντας μια νέα διεργασία (παιδί).
3.  Αναμονή Γονέα: Ο γονέας περιμένει την ολοκλήρωση της διεργασίας του παιδιού πριν επιστρέψει στο prompt.
4.  Αναφορά Κωδικού Εξόδου (Exit Code Reporting): Αναφέρει τον κωδικό εξόδου της διεργασίας του παιδιού.
5.  Χειρισμός PATH: Χρησιμοποιεί τη λειτουργία αναζήτησης του execvp()

Οδηγίες Μεταγλώττισης (Compilation)-Για να μεταγλωττίσετε και να εκτελέσετε το shell, βεβαιωθείτε ότι βρίσκεστε στον κατάλογο όπου βρίσκεται ο πηγαίος κώδικας (.c αρχείο).
Bash(Γράψτε τη γραμμή εντολών)
gcc -o tinyshell tinyshell.c

Εναλλακτικά για μεταγλώτισση μπορεί να χρησιμοποιηθεί η εντολή : make (που μεταγλωτίζει το makefile το οποίο υπάρχει στον φάκελο)

Οδηγίες Εκτέλεσης (Execution)
Bash(Γράψτε τη γραμμή εντολών)
./tinyshell

ΕΝΤΟΛΕΣ ΓΙΑ ΝΑ ΔΟΚΙΜΑΣΕΤΕ:

Ενσωματωμένες Εντολές (Built-in Commands)

Αυτές οι εντολές χειρίζονται απευθείας από τη γονική διεργασία του shell (γονέα) και ΔΕΝ χρησιμοποιούν fork/exec.

ΕΝΤΟΛΗ                | ΤΥΠΟΣ      | ΛΕΙΤΟΥΡΓΙΑ                                         | ΠΑΡΑΔΕΙΓΜΑ          |ΕΜΦΑΝΙΖΕΙ
----------            | --------   | ----------------------------------------------     | ----------------    |-----------------
exit(πατάμε και enter)| Built-in   | Τερματίζει τη λειτουργία του Tiny Shell.           | tiny_shell> exit    |exiting tinyshell(και τερματίζει)
cd                    | Built-in   | Αλλάζει τον τρέχοντα κατάλογο εργασίας.            | tiny_shell> cd /tmp |
EOF                   | Σήμα       | (Ctrl+D) Σήμα End-Of-File που τερματίζει το shell. | (Πατήστε Ctrl+D)    |Exiting shell on EOF.

Εξωτερικές Εντολές (External Commands)

Αυτές οι εντολές εκτελούνται μέσω fork/execvp σε μια παιδική διεργασία. Ο γονέας περιμένει και τυπώνει τον κωδικό εξόδου (Exit Code).

| ΕΝΤΟΛΗ | ΤΥΠΟΣ     | ΛΕΙΤΟΥΡΓΙΑ                     | ΠΑΡΑΔΕΙΓΜΑ             | ΑΝΑΜΕΝΟΜΕΝΟ OUTPUT                                                 |
|:-------|:------    |:-----------                    |:-----------            |:-------------------                                                |
| pwd    | Εξωτερική | Τυπώνει τον τρέχοντα κατάλογο. | tiny_shell> pwd        | Διαδρομή (π.χ. /home/user) + Child exited with status 0            |
| ls     | Εξωτερική | Λίστα αρχείων και καταλόγων.   | tiny_shell> ls -l      | Λίστα αρχείων + Child exited with status 0                         |
| echo   | Εξωτερική | Εμφανίζει μια γραμμή κειμένου. | tiny_shell> echo Hello | Hello + Child exited with status 0                                 |
| FAILED | Εξωτερική | Εντολή που δεν υπάρχει.        | tiny_shell> nosuchcmd  | execv failed:No such file or directory + Child exited with status 1|


Θεωρία Λειτουργίας: Ο Κύκλος fork-exec-wait

Η βασική λειτουργία του Tiny Shell για την εκτέλεση εξωτερικών εντολών βασίζεται σε τρεις κρίσιμες System Calls:
fork() - Δημιουργία Διεργασίας (Process Creation)
Η fork() δημιουργεί ένα σχεδόν ακριβές αντίγραφο της τρέχουσας διεργασίας (γονέα), γνωστό ως παιδί.
Ο διαχωρισμός αυτός είναι απαραίτητος ώστε η νέα εντολή (π.χ., `ls`) να εκτελεστεί από το παιδί, αφήνοντας τον γονέα ελεύθερο να συνεχίσει τη λειτουργία του shell.

execvp() - Αντικατάσταση Προγράμματος (Program Replacement)
Η execvp() καλείται μόνο από το παιδί.
Αντικαθιστά ολόκληρο τον κώδικα του παιδιού με τον κώδικα του προγράμματος που ζητήθηκε (π.χ., το `ls`).
Δεν δημιουργεί νέα διεργασία, αλλάζοντας απλώς το περιεχόμενο της υπάρχουσας διεργασίας-παιδιού.
Το p στην execvp σημαίνει ότι αναζητά αυτόματα το εκτελέσιμο αρχείο χρησιμοποιώντας τη μεταβλητή περιβάλλοντος PATH.

waitpid() - Συγχρονισμός και Συλλογή Εξόδου
Η waitpid() καλείται από τον γονέα για να θέσει την εκτέλεσή του σε αναμονή, μέχρι να τερματιστεί η παιδική διεργασία.
Αυτή η αναμονή είναι κρίσιμη για τη συλλογή των πόρων του παιδιού (αποφυγή "Zombie" διεργασιών) και για την ανάκτηση του κωδικού εξόδου(WEXITSTATUS) που αναφέρεται στον χρήστη.

Built-in Commands (cd, exit)
Οι εντολές cd και exit εκτελούνται απευθείας από τον γονέα χωρίς fork(). Αυτό είναι αναγκαίο, καθώς πρέπει να επηρεάσουν το περιβάλλον του ίδιου του shell (αλλαγή καταλόγου ή τερματισμός του προγράμματος).

Για να διαγραφεί το εκτελέστιμο αρχείο μπορείτε να πληκτρολογήσετε make clean.
