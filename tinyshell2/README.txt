Ο κώδικας project2.c υποστηρίζει πλήρως I/O Redirection (>,<,>>,2>) και Multi-Stage Pipes (∣).

Οδηγίες Μεταγλώττισης (Compilation)-Για να μεταγλωττίσετε και να εκτελέσετε το shell, βεβαιωθείτε ότι βρίσκεστε στον κατάλογο όπου βρίσκεται ο πηγαίος κώδικας (.c αρχείο).
Bash(Γράψτε τη γραμμή εντολών)
gcc -o project2 project2.c

Εναλλακτικά για μεταγλώτισση μπορεί να χρησιμοποιηθεί η εντολή : make (που μεταγλωτίζει το makefile το οποίο υπάρχει στον φάκελο)

Οδηγίες Εκτέλεσης (Execution)
Bash(Γράψτε τη γραμμή εντολών)
./project2

Ενδεικτικές εντολές που δόθηκαν στην εκφώνηση της άσκησης για να δοκιμάσετε:

Εντολή στο tiny_shell>                           |Αναμενόμενη Συμπεριφορά             |Αναμενόμενο Status
-------------------------------------------------|----------------------------------- |------------------------------
ls -l > output.txt                               |Δεν εμφανίζεται τίποτα στην οθόνη.  |Command 1 exited with status 0
                                                 | Το αρχείο output.txt δημιουργείται |
                                                 | και περιέχει τη λίστα των αρχείων  |
--------------------------------------------------------------------------------------------------------------------------------
ls -l >> output.txt                              |Δεν εμφανίζεται τίποτα στην οθόνη.  | Command 1 exited with status 0           
                                                 | Η έξοδος της ls −l προστίθεται στο |
                                                 |  τέλος του output.txt              |
--------------------------------------------------------------------------------------------------------------------------
ls -l | grep ".txt"                                |Η grep τυπώνει μόνο τις γραμμές που |   Command 1 exited with status 0                                                                                                                                                 
                                                 | περιέχουν .txt (π.χ., output.txt). |   Command 2 exited with status 0                               
---------------------------------------------------------------------------------------------------------------------------                                                                                 
ls -l | grep ".txt" | wc -l                        |Εμφανίζεται ο αριθμός των γραμμών   |   Command 1 exited with status 0
                                                 |  στην οθόνη.                       |   Command 2 exited with status 0
                                                 |                                    |   Command 3 exited with status 0
---------------------------------------------------------------------------------------------------------------------------                              
cat file.txt | grep mystring >> grepresults.txt  |Η γραμμή This line has                     |Command 1 exited with status 0
                                                 | mystring προστίθεται στο grepresults.txt. |Command 2 exited with status 0
 
Προσοχή !!! Πριν την τελευταία εντολή δημιουργείστε το αρχείο file.txt με τις εντολες :
echo "This line has mystring" > file.txt
echo "This line does not" >> file.txt
Για παραπάνω δοκιμές μπορείτε να δοκιμάσετε τις εντολές που δόθηκαν στο pdf της εργασίας για testing.

Για να διαγραφεί το εκτελέστιμο αρχείο μπορείτε να πληκτρολογήσετε make clean.
